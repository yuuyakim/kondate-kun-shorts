# kondate-kun-shorts

献立提案アプリ **献立くん** の、Instagram / TikTok 向け縦型ショート動画をコードで作るリポジトリ。

動画編集ソフトを開かず、HTML と CSS アニメーションで作って画面録画する。
献立データを差し替えれば同じ体裁の動画が何本でも出せる、という運用を狙っている。

- 解像度: 1080 × 1920 (9:16)
- 尺: 15秒
- 音声なし前提（ミュートで再生されても意味が通ること）

## 使い方

```
shorts/01-weekly-memo.html
```

をブラウザで開くだけ。ビルドも依存もない。

| キー | 動作 |
| --- | --- |
| `R` | 最初から再生し直す |
| `G` | セーフエリアの枠線を表示（TikTok / IG のUIが被る範囲の確認） |
| `Z` | 原寸 1080×1920 と画面に合わせた表示を切り替える |
| `H` | 画面下の操作バーを隠す（録画前に押す） |

### 録画する

1. ブラウザを開いて `Z` で原寸表示、`H` で操作バーを隠す
2. `Win` + `G` でゲームバーを出して録画開始
3. `R` で頭から再生
4. 15秒経ったら録画停止

より確実にやるなら OBS で 1080×1920 のウィンドウキャプチャを取る。

### コマ送りで確認する

ヘッドレスの Chrome で、任意の時刻のフレームを PNG に書き出せる。

```powershell
& "C:\Program Files\Google\Chrome\Application\chrome.exe" `
  --headless=new --disable-gpu --hide-scrollbars `
  --window-size=1080,1920 --virtual-time-budget=7000 `
  --screenshot=out\t7000.png `
  "file:///C:/Users/yuuya/test_prj/kondate-kun-shorts/shorts/01-weekly-memo.html"
```

`--virtual-time-budget` がミリ秒。7000 なら再生開始から7秒後の絵が出る。

## 01-weekly-memo

**冷蔵庫に貼ったメモが、夕方の台所で1行ずつ埋まっていく。**

タイトルカードを置かず、メモのレターヘッドにブランドを刷り込むことで、
15秒のうち12秒間「献立くん」が画面に出続ける構成にしている。

### 構成

| 時刻 | 内容 |
| --- | --- |
| 0.0 – 2.4s | フック。「今日なに作る」に、毎晩10分。 |
| 2.4 – 3.0s | メモが落ちてきてマグネットで留まる |
| 3.0 – 6.3s | 月〜日の献立が0.42秒間隔で書かれていく |
| 6.4 – 7.6s | 7日分、10秒で。 |
| 7.6 – 12.0s | 買い物リストが重なる。延べ31品 → 22品 |
| 12.0 – 15.0s | 締め。1食分の提案は、ずっと無料 |

### 数字の出どころ

画面に出る数字は本体リポジトリのシードデータ由来で、作り話をしていない。

- **献立380種** — `backend/db/seeds/menus.sql`（main 316 / side 42 / soup 22）
- **延べ31品 → 22品** — 動画に出る7献立の食材を `menu_ingredients.sql` から集計した実数
- **玉ねぎ 4献立** — 生姜焼き・ハンバーグ・カレーライス・肉じゃが
- **生姜 3献立** — 生姜焼き・麻婆豆腐・鶏の唐揚げ

献立を差し替えたら、この数字も数え直すこと。

### デザイン

| 役割 | 値 |
| --- | --- |
| 夜の台所 | `#101828` |
| 藍 | `#1B2E4A` |
| 菜の花（唯一のアクセント） | `#FFC93C` |
| 生成り（紙） | `#FAF6EC` |
| 墨（紙上の文字） | `#1F2530` |
| 浅葱（弱い情報） | `#86A9C4` |

書体は Windows 標準のみで組んでいる。追加インストールは要らない。

- 見出し — Noto Sans JP Black（焦りの質感）
- 献立名 — UD デジタル 教科書体 NP（手で書いた献立表の質感）
- ラベル・数字 — BIZ UDPゴシック

太いゴシックの見出しから教科書体のメモへ移るところで、
「焦り → 落ち着き」を書体そのものに担わせている。

### セーフエリア

TikTok と Instagram はUIが画面に被る。文字は必ずこの内側に置く。

```
左右 90px / 上 240px / 下 360px
```

`G` キーで枠線を出して確認できる。

## 注意

同じテンプレートをそのまま量産すると、TikTok / Instagram 双方で露出が絞られる。
土台は使い回してよいが、**冒頭2秒のフックと文言は毎回変える**。
