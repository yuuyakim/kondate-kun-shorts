# kondate-kun-shorts

献立提案アプリ **献立くん** の、Instagram / TikTok 向け縦型ショート動画をコードで作るリポジトリ。

動画編集ソフトを開かない。献立データを差し替えれば、同じ体裁の動画が何本でも出る。

- 解像度: 1080 × 1920 (9:16)
- 尺: 15秒 / 30fps / 450フレーム
- 音声なし前提（ミュートで再生されても意味が通ること）

## MP4を書き出す

```bash
npm install
npm run render        # → out/weekly-memo.mp4
```

プレビューしながら数値をいじるなら Remotion Studio。

```bash
npm run studio
```

特定のフレームだけ静止画で確認する。

```bash
npx remotion still WeeklyMemo out/chk.png --frame=189
```

### 書体について

Windows 標準の同梱書体だけで組んでいるので、追加インストールは要らない。
ただし **Linux や CI で描画すると豆腐になる**。そこで回すなら
`@remotion/google-fonts` などで読み込むこと（`src/theme.ts` に注記あり）。

## 構成

| 時刻 | 内容 |
| --- | --- |
| 0.0 – 2.4s | フック。「今日なに作る」に、毎晩10分。 |
| 2.4 – 3.0s | メモが落ちてきてマグネットで留まる |
| 3.0 – 6.3s | 月〜日の献立が0.42秒間隔で書かれていく |
| 6.4 – 7.6s | 7日分、10秒で。 |
| 7.6 – 11.6s | 買い物リストが重なる。延べ31品 → 22品 |
| 11.6 – 15.0s | 締め。URLと料金 |

締めは3.4秒しかないので、覚えて帰ってもらうものを **URLひとつに絞っている**。
菜の花のピルはこの1箇所だけに使い、視線が最後にURLへ落ちるようにした。
料金はその下に小さく置く。無料で試せることを先に見せてから、有料の範囲を隠さずに書く。

**タイトルカードを置いていない。** 最後にロゴを3秒出す代わりに、
メモのレターヘッドにブランドを刷り込んである。
結果、15秒のうち12秒間「献立くん」が画面に出続ける。

## 献立を差し替える

`src/data/week-01.ts` の `week` を書き換えるだけ。

```ts
{ day: "月", name: "豚の生姜焼き", genre: "和食",
  ingredients: ["豚ロース肉", "生姜", "玉ねぎ", "キャベツ"] },
```

**画面に出る数字は、このデータから計算している。**
「延べ31品 → 22品」も「玉ねぎ 4献立」も、食材配列を集計した結果であって
手で書いた定数ではない。だから献立を替えても数字がズレない。

並べるときは spec.md 2.2 の重複回避ルールに従うこと。

1. 同一献立が週内に2度出ない
2. 同一ジャンルが3日以上連続しない

## URLと料金

`src/data/product.ts` が正。

```ts
url: "kondatekun.yuuyakim.com",
premiumMonthlyYen: 300,   // 税込
```

**価格は必ず税込で持つこと。** 消費者向けに提示する価格には総額表示義務があり、
税抜だけを大きく出すのは不可（spec.md の景表法・特商法の節を参照）。
`PREMIUM_LINE` が `（税込）` を自動で付けるので、文言を手で組まない。

### 数字の出どころ

画面に出る数字は本体リポジトリのシードデータ由来で、作り話をしていない。

- **献立380種** — `backend/db/seeds/menus.sql`（main 316 / side 42 / soup 22）
- **食材の対応** — `backend/db/seeds/menu_ingredients.sql`

マーケティング素材で数字を盛ると後から効いてくるので、
出典のない数字は画面に出さない。

## デザイン

`src/theme.ts` が正。

| 役割 | 値 |
| --- | --- |
| 夜の台所 | `#101828` |
| 藍 | `#1B2E4A` |
| 菜の花（唯一のアクセント） | `#FFC93C` |
| 生成り（紙） | `#FAF6EC` |
| 墨（紙上の文字） | `#1F2530` |
| 浅葱（弱い情報） | `#86A9C4` |
| 朱（打ち消し・強調） | `#C9452A` |

書体は3役。

- 見出し — Noto Sans JP Black（焦りの質感）
- 献立名 — UD デジタル 教科書体 NP（手で書いた献立表の質感）
- ラベル・数字 — BIZ UDPゴシック

太いゴシックの見出しから教科書体のメモへ移るところで、
「焦り → 落ち着き」を書体そのものに担わせている。

### セーフエリア

TikTok と Instagram はUIが画面に被る。文字は必ずこの内側に置く。

```
左右 90px / 上 240px / 下 360px
```

## 運用上の注意

同じテンプレートをそのまま量産すると、TikTok / Instagram 双方で露出が絞られる。
YouTube は2025年7月に基準を「inauthentic content」として明確化し、
2026年1月には合計3,500万登録のチャンネルを一斉に永久BANしている。
判定軸は「AIを使ったか」ではなく「量産・使い回しか」。

**土台は使い回してよいが、冒頭2秒のフックと文言は毎回書き直すこと。**
ここを自動化した瞬間に、刈られる側に落ちる。

## ファイル

```
src/
  index.ts            registerRoot
  Root.tsx            Composition の登録
  WeeklyMemo.tsx      動画本体
  theme.ts            色・書体・セーフエリア
  timeline.ts         秒 → フレームの変換と、動きのヘルパ
  data/week-01.ts     献立データと、そこから計算する集計値
shorts/
  01-weekly-memo.html Remotion化する前のプロトタイプ（ブラウザで開くだけで動く）
```

`shorts/01-weekly-memo.html` は依存ゼロで動くので、
絵の方向性を素早く試すときはこちらが早い。
